# Standard weights for count-only items

Use these so conversions are consistent across books. Values are rounded USDA FoodData Central household weights or typical package weights; edible portion unless noted. If an item isn't listed, use a USDA household weight or the package's serving weight and say which in Notes. If the book gives grams anywhere (including a footnote), use the book's grams instead.
